# QQWAPI.cn（BOLI AI）产品功能需求文档

版本：v1.0（2026-09-23）  
目标：作为开发一套同类 AI 平台的产品、交互与后端实施依据

## 0. 调研口径与证据边界

本文件以 `https://www.qqwapi.cn/` 的公开入口、公开前端路由/资源和无需登录的公开 API 为主要证据，已核对到：站点配置、登录配置、模型别名目录、定价目录、会员套餐、智能体目录、灵感分类、CLI 下载契约等。当前环境没有可复用的浏览器登录会话，因此无法对登录后页面进行人工点击验收；登录后能力依据公开前端代码、接口路径和文案归纳。文中标记“[事实]”的是已观察到的功能，“[推测]”是为实现同类产品必须补齐的后台或工程设计。

站点公开 API 统一以 `/api` 为前缀。模型“展示目录”“平台别名”“渠道真实模型 ID”必须分层保存，前端和 API 调用不得混用。

## 1. 产品概述

### 1.1 产品定位

BOLI AI 是“一站式 AI 技术栈和内容生态平台”，同时扮演四种角色：

1. **多模型聚合网关**：统一接入聊天、图像、视频、语音和智能体能力，用户只选择平台别名，不感知供应商路由。
2. **AI 创作工作台**：围绕文本、图片、视频、音频与短剧/电商场景，把生成任务、作品、参考资产和历史记录放在一个工作区。
3. **智能体与课程生态**：提供官方智能体、社区智能体、工作流模板、小课堂课程、公开作品和创作者收益。
4. **开发者与渠道基础设施**：提供 API Key 网关、CLI、设备授权、MCP/Codex 接入、渠道经营看板和企业合作入口。

### 1.2 目标用户

| 用户群 | 主要目标 | 关键需求 |
|---|---|---|
| AI 普通用户 | 对话、写作、问答 | 模型切换、流式响应、低门槛注册、按量付费 |
| 内容创作者 | 图像/视频/配音/短剧生产 | 多模态生成、参考素材、异步任务、作品资产复用 |
| 电商与自媒体运营 | 商品图、海报、爆款拆解 | 批量处理、提示词复用、平台内容适配 |
| 漫剧/短剧团队 | 从小说/剧本到分镜和成片 | 剧本、角色、场景、分镜、视频的一体化流水线 |
| 教育/知识创作者 | 课程与资料转内容 | PDF 解析、知识成图、课程发布、收益结算 |
| 开发者/AI Agent 用户 | 将能力接入应用或本地 Agent | API Key、模型目录、CLI、MCP、报价确认 |
| 企业/渠道伙伴 | 采购、代理、客户运营 | 统一算力、兑换码、渠道分成、经营数据、客服 |

### 1.3 核心价值与商业模式

- **统一入口**：用一个账号管理模型、工具、智能体、作品和权益。
- **按量算力**：以算力点数作为平台结算单位；聊天按 Token，图片/视频/音频按次、秒或字符等模型规则计费。
- **会员折扣与额度**：月/季/年会员获得算力、功能折扣和专项图像额度；合伙人会员增加现金返佣能力。
- **内容生态变现**：智能体调用收益、课程销售/学习分成、推广链接奖励和钱包提现。
- **开发者收费**：API Key 直连生成请求可能直接扣费；CLI/MCP 的设备链路采用“报价→用户确认→提交”的二次确认机制。

调研时公开 `/api/pricing` 返回约 114 个聊天、55 个图片、62 个视频、10 个音频模型，并另有智能体/复合视频/视频处理类价格项；公开“平台别名”目录返回 23 个聊天、21 个图片、18 个视频、5 个音频别名。以上数量是动态运营数据，开发实现必须以接口实时结果为准，不得写死。

### 1.4 建议的首期成功指标

注册完成率、首个生成任务完成率、首充转化率、生成任务成功率、7 日作品复用率、智能体调用次数、API Key 首次调用成功率、退款/争议率、会员续费率。

## 3. 功能需求详述

### 3.1 全局壳、导航与页面布局

**页面结构**

- 公共页：顶部品牌导航、主导航项、主题切换、登录/进入工作台、客服入口；营销页采用“英雄区→能力/价值区→流程/价格→CTA→页脚”结构。
- 工作台：左侧主导航/会话或智能体目录，中间主工作区，右侧作品/资产/任务栏；工具页可切换为“配置区 + 结果区”或“目录 + 详情”双栏。
- 账户页：左侧分组菜单，右侧卡片式内容区；移动端改为抽屉/底部导航。
- 异步任务：所有生成类任务显示状态、耗时、失败原因、重试/查看原任务，右侧“最近作品”实时刷新。

**全局交互规则**

1. 需登录功能统一跳转 `/login?redirect=原路径`，登录成功后返回原路径。
2. 主题支持深色/浅色，主题偏好存储于本地。
3. 余额不足时打开充值弹窗，不清空当前输入和已生成作品。
4. 网络或服务不可用时保留登录态，显示“重新连接”而不是强制退出。
5. 错误消息要区分：参数错误、内容安全、模型不可用、余额不足、限流、任务超时和未知提交结果。

### 3.2 注册、登录与账户安全（P0）

**入口与页面元素**

- 登录/注册弹窗标题“登录 / 注册”；手机号验证码、邮箱验证码、密码登录三个 Tab，按后台开关动态显示。
- 字段：手机号/邮箱/用户名、验证码、密码、邀请码、同意《用户协议》和《隐私政策》；密码登录增加滑块验证和“记住密码”。
- 验证码按钮 60 秒倒计时；首次注册提示赠送算力。

**已观察配置**

`GET /api/auth/login-config` 当前返回：手机号/邮箱/密码均开启；注册赠送 150 算力；邀请码奖励 350 算力；邀请码可见但非必填；短信/邮箱发送和登录需要人机校验；密码登录滑块校验关闭；连续失败 5 次锁定 15 分钟；验证码有效期 10 分钟。

**业务规则**

1. 手机号或邮箱验证码登录：已注册直接登录，未注册自动创建账号；注册时写入邀请码并发放注册奖励。
2. 密码登录支持用户名、手机号、邮箱；用户可在个人中心设置密码，设置密码不影响验证码登录。
3. 发送短信/邮箱前调用 `/auth/captcha/generate` 和 `/auth/captcha/verify`；登录/发码接口携带 captcha token。
4. 必须勾选协议才能提交；格式校验手机号（中国大陆 11 位）和邮箱。
5. PC 与移动端 token 分离（`boli_token` / `boli_mobile_token`）；禁止用移动端 token 调 PC 接口。
6. 登录成功返回 JWT 与用户资料；401 触发登录失效提示，受保护路由回到登录页。

**边界与安全**

- 验证码过期、频繁发送、登录锁定、邀请码失效、账号已封禁均返回可读错误。
- 不在前端保存明文密码；“记住密码”应改为安全凭证或默认关闭。
- 后台需支持登录开关、注册开关、奖励值、锁定阈值和验证码策略配置。

### 3.3 AI 创作工作台（P0）

#### 3.3.1 工作台公共能力

**输入**：当前能力类型、模型别名、文本提示词、参考文件/作品、比例/清晰度等参数。  
**输出**：聊天消息或异步任务 `job/work`，同步写入作品库和算力流水。

- 会话：新建、切换、重命名、删除、最近会话；接口对应 `/api/chat/sessions`、`/messages`。
- 资产引用：从右侧作品拖入提示词；支持预览、移除、排序、类型校验。
- 结果操作：预览、下载、复制文本、再次生成、查看任务详情、删除/分类。
- 任务状态至少为 `queued/submitting/processing/succeeded/failed/expired/cancelled/refunded/unknown`。
- 计费采用服务端最终价；失败是否退还由服务端账本决定，前端不可自行改余额。

#### 3.3.2 大模型对话（P0）

**页面**：模型选择器、能力标签、会话列表、消息流、附件条、输入框、发送/停止按钮、Token/算力提示。

**输入**

- `model`：只允许 `GET /api/model-aliases/public?capability=chat` 或 `/api/v1/models` 返回的平台别名。
- `messages[]`：`role` + `content`；可选 `stream`、`max_tokens`、`temperature`。
- 附件：图片、PDF、DOCX、TXT、MD、CSV、XLS/XLSX、PPT/PPTX、JSON、XML、HTML；按模型能力限制大小、字符数和数量。

**输出**

- 非流式：消息、`usage`、计费信息；流式：SSE 增量消息，前端逐段渲染 Markdown。
- 失败：展示模型不可用、上游认证、限流、敏感内容或额度不足，并保留用户草稿。

#### 3.3.3 图片生成（P0）

**页面**：提示词区、图片模型、参考图列表、比例、分辨率（1K/2K/4K）、画质、张数、生成按钮、批量任务队列、结果画廊。

**输入**：`model`、`prompt`、`n`、`ratio`、`resolution`、`quality`、参考图 URL/站内 objectKey。模型能力从公开别名目录读取，动态控制支持的比例、清晰度、参考图数量。

**输出**：图片 URL/作品记录、任务 ID、实际扣费、失败原因。生成前应显示估算/实际单价，提交后不可更换模型参数。

**边界**：参考图数量超限、真人/敏感内容、无效 URL、模型不支持的组合、余额不足、任务卡住。失败应查询原任务并按账本规则退款，不重复创建付费任务。

#### 3.3.4 视频生成（P0）

**模式**：文生视频、图生视频、图片参考、多图参考、首尾帧、全能参考、智能多帧；部分模型支持参考视频、参考音频和生成音效。

**输入**：视频模型、提示词、参考图/首帧/尾帧/视频/音频、比例、清晰度、时长 3–30 秒、是否生成音效。

**输出**：提交返回 `processing + taskId` 仅表示受理；前端轮询 `/api/video/status?taskId=` 或 `/api/v1/videos/generations?taskId=`，成功后写入作品库并展示视频 URL。

**规则**

1. 模型能力决定时长、分辨率、参考素材上限；“目录可见”不代表“当前可执行”。
2. 提交后必须按原 taskId 查询，不得因超时/未知状态换模型重建。
3. 真人参考、肖像、隐私信息和敏感内容触发合规提示；提示用户换素材、文生视频或开启合规增强（若该模型支持）。
4. 失败、超时、卡住、内容审核失败分别展示；只有后端明确退款才显示“算力已退回”。

#### 3.3.5 音频能力（P0/P1）

- **TTS**：输入文本、音频模型、音色、格式（MP3/WAV）、语速；输出音频二进制/下载 URL。公开目录提供中、英、日、韩、西、葡等多语言音色。
- **ASR**：输入音频文件、Base64 或 URL、语言；输出转写文本。
- **音乐生成**：输入音乐风格、情绪、节奏、乐器、是否含歌词；输出音频任务。
- **声音克隆**：输入一段参考音频 + 文本；一次仅允许 1 个参考音频，需额外权限/高价计费。
- 错误时同时检查 HTTP 状态与 Content-Type，因为部分语音错误响应可能没有 JSON body。

#### 3.3.6 多模型协作（P1）

提供并行回答、辩论、翻译对比、创意碰撞和多角度分析。输入为问题、模型列表、协作模式和输出格式；输出为分模型结果、汇总结论、各模型耗时与算力消耗。至少支持“每个模型单独计费、总价预估、取消未完成任务”。

### 3.4 智能体目录、调用与创作者中心（P1）

#### 3.4.1 发现与调用

- `/discover` 为未登录可访问的精选助手页：关键词搜索、分类筛选、热门推荐、卡片（名称、描述、标签、免费/计费、官方/社区、使用次数），点击“开始对话”进入工作台。
- 工作台智能体目录从 `/api/agents/discover`、`/categories`、`/recent`、`/favorite`、`/my` 读取；当前公开目录可返回约 65 个智能体，分类包含写作助手、视频分析、实用工具、代码助手、教学课程、花样智能体。
- 调用输入为智能体 ID + 用户消息 + 可选附件/上下文；输出为流式或一次性文本/异步任务。计费类型支持 `per_token`、`per_use` 和免费/免费次数。

#### 3.4.2 创建与审核

表单字段：名称、图标、封面（16:9）、简介、分类、基础模型、系统提示词、欢迎语、计费模式（完全免费/先免费后计费/直接计费）、免费次数。支持上传图片、保存草稿、提交审核、编辑、删除、发布/下架。

规则：

1. 新建申请先进入审核队列，审核通过后才可公开发布。
2. 系统智能体与社区智能体使用不同徽标、权限和收益规则。
3. 提示词必须定义角色、能力边界、输出格式、语气和禁止事项；后台需做敏感词和越权检查。
4. 统计调用次数、算力、收益和退款；创作者可在个人中心查看并申请提现。

#### 3.4.3 工作流模板与多模态智能体

模板可组合站内能力（聊天、图片、视频、分析、课程等），保存步骤顺序、输入映射、默认参数、失败回滚策略和计费模式。执行前展示预计步骤和可能费用；任何付费步骤都需要余额检查。

### 3.5 AI 工具箱与专项工具（P0/P1）

工具箱目录应至少覆盖：爆款视频拆解、抖音视频下载、视频字幕擦除、AI 摄影工作室、电商图片工厂、AI 海报、数字人视频、AI 视频、短剧带货工厂、剧本提示词、仙侠剧本台、剧本记忆层、智能仿写、转口播稿、人物优化、批量换风格、视频增强、PDF 智能分析、资料问答、AI 员工、风格分析、音频/配音工具。

每个工具必须声明：输入类型、是否登录、是否计费、支持模型/文件格式、同步或异步、结果保存位置、失败是否退款。工具历史统一写入 `/api/ai-tools/history`，支持回看、导入草稿和删除。

#### 3.5.1 今日素材/知识成图（/linyi）

1. 上传 PDF（教材、讲义、论文）并调用 `/api/linyi/pdf/parse`。
2. 将解析内容整理成 N 条知识点；用户可修改标题/正文、重新合并为目标数量。
3. 为每条知识点选择图片模型、风格、补充要求、尺寸、分辨率、张数；支持自定义风格和补充要求模板。
4. 单条生成或一键批量生成，结果进入图库并按 PDF 文件名分组；历史只保存 3 天，支持预览、下载、清空。
5. 无图片模型、解析失败、批量中断时保留已完成项，不重复提交已完成任务。

#### 3.5.2 剧本导演（/script-director）

流程：需求 → 剧本（场景+动作+台词）→ 人物绘图提示词 → 分镜提示词 → 配音文案 → 视频模型/画幅/清晰度/时长 → 提交站内视频接口。

输入需支持手工编辑每一步输出；输出必须带任务 ID、状态和视频 URL。任一步失败可单独重跑，不丢失上游结果。

#### 3.5.3 电商 AI 一键工厂（/ecom-factory）

提供热门图片素材库、搜索标题/关键词、视觉方向和比例筛选；查看压缩图或 4K 原图，下载参考图，查看完整/精简提示词；选择图片模型和 1:1/横版/竖版后一键生成同款。生成中允许关闭弹窗继续浏览，结果回写作品库。

#### 3.5.4 爆款视频分析

输入支持视频 URL、本地视频或分片上传；后台任务解析视频、关键帧、音频和字幕，输出爆款原因、脚本、镜头和资产建议。需要显示上传进度、任务状态、取消、重试和导入“抄爆款草稿”按钮。视频时长和大小必须在前端预校验，服务端再次校验。

### 3.6 作品、素材与存储（P0）

**作品中心**

- 类型：图片、视频、音频、文本、对话结果、课程/画布结果。
- 视图：最近作品、分页列表、网格卡片、预览弹窗、下载、复制、删除、分类筛选。
- 文本资产：标题、正文、分类（剧本、人设、世界观、提示词、分镜脚本、旁白文案等），支持加入文本库、编辑和引用。
- 媒体资产：角色、场景、道具、分镜图、风格参考、镜头参考、动作参考、配音、音效、背景音乐等二级分类。

**存储与限制**

接口：`/api/works/list`、`/recent`、`/upload-asset`、`/text-assets`、`/api/storage/summary`、`/api/storage/packages`。超出空间时阻止上传并引导购买扩容；删除需二次确认，后台应支持软删除与恢复窗口。

### 3.7 算力、充值、支付、会员与活动（P0）

#### 3.7.1 算力账户

个人中心展示当前余额、累计充值、累计消耗和可用权益；流水类型至少包括充值、赠送、功能消耗、兑换码、失败退还、会员购买、课程/智能体收入。

每笔扣费必须包含业务类型、模型/工具、原价、会员折扣、最终价、任务 ID、账本流水 ID、状态。前端状态至少支持处理中、已完成、已退款、失败、已关闭。

充值弹窗展示算力套餐、赠送、会员价/普通价和支付方式；支付接口包含支付宝、微信、汇付，创建订单后轮询 `/api/payment/status` 或 `/api/payment/query?orderNo=`，回调成功后刷新余额。支付超时不得重复扣款，订单号必须幂等。

#### 3.7.3 兑换码与内容激活码

- 算力/会员兑换码：同一输入框自动识别类型；会员兑换按延长/升级规则生效，附赠算力同时到账。

#### 3.7.4 会员

`/api/membership-benefits/plans` 当前返回月度初级/中级/高级和年度合伙人方案；页面必须动态读取后台套餐，不把价格硬编码。套餐字段：价格、原价、有效期、到账算力、周期、服务折扣、专项图片额度、额外权益。

公开配置体现的权益：普通会员约 95/90/88 折；合伙人会员约 80 折并可启用分享充值现金返佣；1K/2K/4K 图像额度按套餐赠送且有独立有效期。购买周期支持月付、季付、年付，页面显示一次性到账或每月加赠规则。

#### 3.7.5 活动与分享

活动中心展示已到账权益、剩余额度、会员功能、分享注册奖励、首充奖励、返佣比例和有效期；分享流程：创建推广链接 → 好友注册绑定 → 好友充值 → 奖励入算力或钱包。合伙人现金返佣和普通用户算力奖励分开核算。

### 3.10 开发者 API、CLI 与 MCP（P0/P1）

#### 3.10.1 API Key

入口 `/api-docs` 或个人中心“API 密钥”。创建字段：密钥名称、权限多选、速率限制（次/分钟）、过期时间。权限至少覆盖 `chat/image/video/audio/agent/multi_agent/analyze/course`（实际以后台允许集合为准）。列表展示掩码、启用/禁用、权限、速率、创建时间；支持删除和一次性 reveal。

规则：完整 Key 只在创建时显示一次；调用使用 `Authorization: Bearer {API_KEY}` 或 `x-api-key`；API Key 不得用于 `/api/cli`、`/mcp`；日志不得记录完整 Key。

#### 3.10.2 API 端点契约

| 能力 | 方法/路径 | 关键输入 | 关键输出/边界 |
|---|---|---|---|
| 模型发现 | `GET /api/v1/models` | 可选 `type` | 仅返回聊天别名；图片/视频/音频从公开别名目录读取 |
| 对话 | `POST /api/v1/chat/completions` | `model`、`messages`、`stream` | OpenAI Chat Completions 兼容；流式 SSE |
| Responses | `POST /api/v1/responses` | `model`、`input`、`stream=true` | 仅支持流式，可能桥接 Chat Completions |
| 图片 | `POST /api/v1/images/generations` | `model`、`prompt`、`n`、尺寸/质量 | 可能直接计费，返回图片数据/URL |
| 视频 | `POST /api/v1/videos/generations` | `model`、`prompt`、时长、分辨率 | `processing + id` 仅受理；必须查询原任务 |
| 音频 TTS | `POST /api/v1/audio/speech` | JSON `model/input/voice/format/speed` | 成功返回音频二进制 |
| 音频转写 | `POST /api/v1/audio/transcriptions` | JSON `model` + `audio` Base64 或 `url` | 非 multipart；返回上游 JSON |
| 余额 | `GET /api/v1/balance` | 无 | 返回算力余额 |
| 智能体 | `POST /api/v1/agents/chat` | agent ID、消息 | 按智能体规则计费 |
| 多模型 | `POST /api/v1/multi-agent/execute` | 模型列表、协作模式、消息 | 返回多模型结果和费用 |

强制校验：`model` 必须是平台别名，禁止使用 `/api/models/public` 的渠道 ID；HTTP 200 不等于视频成功；错误响应通常为 `{error:{message,type}}`。

#### 3.10.3 CLI 设备授权

公开 `GET /api/public/cli` 当前返回 `boli-cli 0.3.7`、Node.js `>=20`、latest/fixed 下载地址和模型目录地址。安装、版本查询不需要登录。

设备登录默认只申请 `account:read/balance:read/models:read/capabilities:read`；图片、视频、工具箱、MCP 权限必须用户在网页授权页显式批准。设备 token、主站 JWT、API Key 三者不可混用。

图片链路：报价 → 展示模型/参数/费用 → 用户确认 → 提交 → 查询状态 → 可选下载。视频链路：报价/精确参数 → 用户确认 → 提交文生视频 → 查询原任务；不支持用失败结果换模型重建。工具箱首期仅爆款视频解析，报价按“视频时长 × 每秒价格”预扣。

#### 3.10.4 MCP/Codex

端点为站点根路径 `POST /mcp`，不是 `/api/v1/mcp`；采用 Streamable HTTP JSON 子集，支持 `initialize/ping/tools/list/tools/call`。Codex 侧推荐本机 `boli mcp serve`，配置只写 command/args，不写 token。付费 MCP 工具必须先返回报价，待用户确认后再提交。

### 3.11 安卓端（P1）

当前产品配置为 Android 7.0+、约 5.4MB；登录用户且满足会员或已激活内容权益方可下载。APP 与网页版共用账号、会员、算力、兑换码和云端作品库；生成任务在云端运行，关闭 APP 后可继续。下载页提供权限校验、二维码/客服、安装未知来源说明和常见问题。

### 3.12 渠道后台与接口自检（P1/P2）

- `/channel/login`：渠道账号、密码登录；与主站 JWT 隔离。
- `/channel/dashboard`：按今日/近 7 天/近 30 天/本月/季度筛选，展示充值金额、新增用户、算力消耗、预估分成、待审核/已确认/已打款结算、渠道下代理/用户、趋势、代理贡献和分成规则。

## 4. 用户流程说明

### 4.1 普通用户首次创作

1. 进入首页 → 点击“开始使用”。
2. 选择手机号/邮箱验证码或密码登录；未注册自动创建，获得注册算力。
3. 进入工作台，默认打开对话或全能助手；选择模型别名并输入需求。
4. 流式查看结果；结果自动进入会话和最近作品。
5. 选择图片/视频/音频能力时填写参数并提交；查看任务进度和结果。
6. 余额不足 → 充值套餐/兑换码 → 支付回调成功 → 保留原草稿并重新提交。
7. 在作品中心下载、分类、复用或删除结果。

### 4.2 创作者发布智能体/课程

1. 个人中心 → 创作者中心 → 选择“申请创建智能体”或“申请创建课程”。
2. 填写资料并提交审核；状态为审核中，不显示公开发布按钮。
3. 审核通过后创建智能体/课程草稿，完善提示词、封面、章节和内容。
4. 提交发布审核；通过后进入探索/小课堂/智能体目录。
5. 用户调用/购买/学习后产生收益；创作者在收益页查看调用、销售、待结算和可提现余额。
6. 钱包提交支付宝/银行卡提现，等待后台审核和打款。

### 4.3 开发者接入 API

1. 打开 API 文档 → 登录 → 创建 API Key → 选择权限、速率和有效期。
2. 复制一次性完整 Key 并安全保存。
3. 调用模型目录获取平台别名；按能力发送 Chat/Image/Video/Audio 请求。
4. 对视频用返回 taskId 查询原任务；对流式接口按 SSE 解析。
5. 在个人中心查看消费流水、Key 状态和余额；Key 泄露时立即禁用/删除。

### 4.4 CLI/MCP/Codex 接入

1. 无登录下载 CLI，检查 Node 版本和 `boli --version`。
2. `boli auth login` 打开网页授权；用户选择要批准的付费 scope。
3. CLI 拉取图片/视频真实别名，用户手工选择默认、第一备用、第二备用。
4. 每次付费任务先报价；用户确认精确报价后再提交。
5. Codex 另行安装 `boli mcp serve`，配置不写 token，完全重启 Codex 后检查工具列表。

## 7. 开发实现约束与验收标准

- 所有付费操作使用服务端幂等键；“请求已受理”不得当作“结果成功”。
- 任何任务出现未知状态时，只允许查询原任务；禁止自动换模型、换工具或重复扣费。
- 模型别名、渠道真实 ID、展示名称分离；前端只提交后端下发且当前可执行的别名。
- 余额、会员折扣、权益额度和退款以账本为唯一事实源；前端缓存只做展示。
- 文件上传必须限制 MIME、大小、时长、分辨率和恶意内容；对象存储 URL 应签名并设置过期时间。
- API Key、JWT、设备 token 分域隔离，不写入 URL、日志、示例配置或 Codex 配置文件。
- 所有异步任务可取消（若后端支持）、可重查、可恢复；页面刷新后从服务端恢复状态。
- P0 页面需覆盖 PC 与移动响应式；P1 安卓下载/APP 复用同一账户、权益和作品接口。
- 验收至少包括：正常成功、余额不足、权限不足、模型下线、参数不支持、敏感内容、限流、超时、重复提交、未知结果、退款和断网恢复。

### 9.8 登录态与跨路由问题（实测风险）

在已登录移动端页面中点击底部“创作”或首页工具入口后，页面跳转到公共根路径 `/`；随后再直接访问 `/m/home` 或 `/m/me` 时，出现公共首页/登录弹窗而非工作台。当前只能确认“跨移动端工作台与公共/PC 路由的会话保持异常”，不能仅凭前端现象断定是 token、路由守卫还是浏览器上下文问题。

**P0 验收要求**

1. 已登录用户从任一移动端功能入口进入公共页、PC 工作台、课程、工具详情后，应保持同一账号和权益；返回原页面不应重新登录。

### 10.13 PC 端关键异常与 P0 验收项

本轮与前述工作台检查合并后，发现以下跨路由和账务一致性问题：

- 移动端从创作/工具入口进入公共根路径后可能丢失登录态；PC/移动路由需要统一会话恢复策略。
- PC 个人中心“工作流模板中心”跳转 `/?invite=WORKFLOW-LAB&register=1&login=1` 并弹出登录注册框，疑似占位链接、错链或未完成授权流程。
- PC 工作台点击“无限画布”后按钮变为 active，但 URL 和主体仍停留在 `/agents/toolbox`，疑似入口未实现或路由状态失配。
- PC 工作台点击 Codex 进入公共 `/codex`，不是工作台内部页面；需要明确这是外部产品、公共落地页还是应保留登录态的工作区。
- 同一账号此前移动端显示 441 算力，本次 PC“我的算力”显示 521 算力；PC 账单显示充值 +350、对话消耗 -59、流水 2 条。当前不能断定是快照时间、赠送余额、端侧缓存或账本来源不同，但属于 P0 账务一致性风险。
- 安卓端与工作台均宣称权益、算力和作品云端同步，但当前余额、激活资格和下载权限没有可见的统一快照时间或刷新状态。

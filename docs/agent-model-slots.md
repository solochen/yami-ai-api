# 智能体模型配置

后台入口：`/admin/agent-models`（侧栏「智能体模型配置」）。包含停用智能体、系统工作区、自定义模型节点及内置提示词智能体。

每个槽位显示用途、必需能力、当前模型、兼容状态和配置来源。候选来自服务端；满足全部必需能力的模型可选，能力更多的模型也可选。缺失、停用、不兼容或来源不一致的历史配置会提示问题，不会批量改写。

## 接口

均使用现有 admin 登录鉴权：

- `GET /admin/api/agent-models`：全部智能体及其槽位、候选和能力说明。
- `GET /admin/api/agents/:code/models/:slot/candidates`：查询单个槽位的候选。
- `PUT /admin/api/agents/:code/models/:slot`：替换单个槽位。

示例：

```json
{
  "model_code": "compatible-model-code",
  "expected_model_code": "previous-model-code"
}
```

`slot` 使用总览返回的 `id`，例如 `analysis_model_code`、`image_model_code`、`dialogue_model_codes.1` 或 `node.custom-node`。`expected_model_code` 用于检测并发修改；继承槽位使用返回的 `configured_model_code`（通常为空），不要使用解析继承后的 `model_code`。

服务端拒绝这个接口中的额外字段，客户端不能提交能力规则。更新对工作流行加锁，只修改目标槽位及其明确的镜像引用，保留提示词、计价、策略、其他槽位和节点自定义字段。操作写入现有管理员日志。

写真、试穿、小说、视频超分/重绘/去字幕等专用流程按实际运行字段合并展示节点；修改一个槽位会同步这些节点。小说的章节创作、润色和归档共用生成模型。自定义工作流节点保留独立槽位，缺少模型的可调用节点仍可配置；漫剧本地视频合成不作为模型槽位。实时数字人与商品图片提取等无模型库绑定的智能体显示其服务或本地处理来源。

## 服务端能力契约

`services/modelcontract` 是 API 和 worker 共用的 Go 模块：

- `contract.go`：槽位职责、固定智能体约束、能力解析和模型匹配。
- `store.go`：读取模型与线路的能力元数据，不读取密钥或价格。
- `comic.go`：计算漫剧剩余调用阶段，使续跑只校验实际需要调用的模型，保留已完成素材。

新接口、原工作流创建/编辑接口、模型覆盖、重试、自动回退及 worker 执行均使用这些规则。内置智能体的能力要求由编码固定，不能通过改变 `agent_mode` 或关键节点的 `type` 来降低。

兼容专用流程的旧请求参数：写真、试穿、小说的 `model_code`，以及漫剧重试的 `dialogue_model_code` 也会先映射到对应槽位后校验。

主要要求：

| 槽位 | 必需能力 |
| --- | --- |
| 爆款结构分析 | 聊天 + 图片理解 + 视频理解 |
| 关键帧 | 图片生成 + 参考图输入 |
| 视频片段 | 视频生成 + 首帧或参考图输入；明确使用首帧的流程要求首帧 |
| 配音 | 音频类别 + 语音合成 TTS |
| 配乐 | 音频类别 + 音乐生成 |
| 视觉分析/验收 | 聊天 + 图片理解 |
| 商品局部编辑 | 图片生成 + 参考图 + 兼容蒙版编辑的 OpenAI Images 线路 |
| 试穿 | 图片生成 + 多参考图输入 |
| 超分/重绘/去字幕 | 视频类别 + 对应专用能力 |

能力使用模型配置、输入模式和线路覆盖解析，信息不足时不进入相应候选。显式关闭优先于同层旧别名；线路覆盖优先于模型默认。模型配置了线路时，必须有启用线路，并且所有启用线路都兼容，防止重试切到不兼容线路；没有独立线路的模型可以使用平台默认网关。

图片理解兼容 `vision`、`image_input`、`multimodal`；视频理解兼容 `video_analysis`、`video_input`、`video_understanding`。参考图读取 `image.max_reference_images` 与参考输入声明；视频读取实际输入模式及上传配置。配音优先读取 `capabilities.speech_synthesis` / `tts`，兼容明确的语音合成端点；音乐使用 `music_generation` 或明确的音乐端点。未知音频接口需要在「模型管理 → 音频生成能力」中声明实际用途。模型名称不会被用来猜测能力。

这些校验依赖管理员维护的真实能力元数据，不会为了打开候选而自动开启模型能力，也不会发起付费探测或生成。

## 默认值和已有任务

画布提示词增强依次使用本智能体的增强模型、分析模型、通用创作的分析模型。页面显示继承来源和共享影响，在继承槽位保存会为当前智能体写入独立默认值。提示词智能体缺少显式模型时显示其内置提示词包默认值。

画布新增节点和模板会采用配置的默认模型，已有节点保留自己的选择。后台替换模型不会重跑已完成素材。

## 验证与运行

```sh
cd services/modelcontract && go test ./...
cd services/api && go test ./...
cd services/worker && go test ./cmd/worker
cd apps/admin && pnpm build
```

数据库回归通过 `AGENT_DRAFT_TEST_DATABASE_URL` 指向可创建临时 schema 的本地 PostgreSQL，测试自行隔离并清理，不调用生成供应商。

API 和 worker 新增了本地模块依赖，Docker 构建上下文已改为仓库根目录。开发与生产 Compose（包括迁移工具）的配置已同步。已有运行容器需要重新构建后才能提供新接口和执行校验；仅启动前端不会更新运行中的后端。
